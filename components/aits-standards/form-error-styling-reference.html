Specifications:
  • Wrapper left border (error): 4px solid #d32f2f (changes from transparent)
  • Wrapper padding-left: 12px
  • Input border (error): 2px solid #d32f2f
  • Input background (error): #fef7f7 (optional subtle tint)

  • Error message color: #d32f2f
  • Error message size: 0.875rem (14px)
  • Error message margin-top: 4px
  • Label color: remains #333 (do not change)
CSS Automation:

The error styling is applied automatically using the :has() selector. Developers only need to add is-visible to the error div and aria-invalid="true" to the input. The wrapper's red border and input styling appear automatically via CSS.
