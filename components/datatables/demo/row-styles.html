Row Style Examples

Datatables has a built-in "stripe" class for alternating row colors, but you can also use one of the following classes for row styling:

  • rows_gray
  • rows_blue
  • rows_lightBlue

Add the class "hover" in addition to one of the above classes to the table to have a hover effect on the rows.
