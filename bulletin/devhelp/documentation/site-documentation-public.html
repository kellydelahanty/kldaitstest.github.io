The grid layout css classes are applied to the nav instead of a div to layout the sidebar navigation section in relation to the rest of the page the rest of the page conent.

The nav should also be given aria-label="[Section title] Section Subnavigation" where "[Section Title]" is replaced by the parent section title for the page in question. For example, "About the Bulletin" would be the section title for all the pages in the "About the Bulletin" section.

The page the user is currently on is given the class current.

The sidebar subnavigation disappears on small screens and users are expected to use the main navigation with it's dropdowns to get to subpages

Homepage Search/Call-to-Action Block

The search and call-to-action block appears in a contact-block with the additional blue-block class. Directly within that contact-block div is a grid-container with the additional grid-gap-10 class. Within the grid-container there are 4 cell divs.

The first cell div has no additional classe and contains the h1 for the page.

The second cell div has an additional class of hp-search and contains a form. Within the form is another grid-container grid-gap-10 div with two cell divs inside it. The first cell div also has the class hp-search-input and has the label, input and "Advanced Search" link. The second cell has the additional class of hp-search-button and contains the search button.

The third and forth cell divs have the additional class hp-cta. Inside this div is a div with the class img-link. See the Image + Link section for more information.

Homepage blurbs & layout

All the content on the homepage below the search block is in another content-block div, this one without an additional class to assign color. Inside the content-block is a grid-container with the grid-gap-10 class. Within the grid-container there are three cell divs, each with the additional class of hp-section.

Each of these hp-section divs contains another grid-container div, within which there are two cell divs. The first cell div will contain the text and links of the section, and the second will contain the image. The text div should always come before the image div in the HTML - the display order of the divs will be handled through specialized css classes.

For the first hp-sectionon the page,this cell div gets the class hp-blurb-1. The second cell gets the class hp-blurb-2, and the third gets the class gets the class hp-blurb-3.

The second cell in the grid-container within hp-section contains the image file. For the first hp-sectionon the page, this cell div gets the class hp-img-1, and the second and third get the classes hp-img-2 and hp-img-3 respectively.

News articles on Homepage

The news section of the homepage has a unique layout situation in order to contend with the fact that the number of articles that show up on the page is variable. This articles in this section will adjust their width based on how many articles there are so that the section takes up the full width of the site on large screens. This works well for 1-3 articles, but it's not advisable to go past that.

Put the news section in its own content-block div. Inside the div with the classes grid-container grid-gap-10. Inside the grid-container are two cell divs. The first cell just has the h2 for the section.

The second cell contains a div with the classes hp-news bottom-divider. Each news posting is in an article. Each article contains:

  • A h3 that is a link to the full article.
  • A p with the class article-date that contains the date the article was posted.
  • A p with the class article-preview that contains the post summary.

Illustrated Sections

There are a few places in the application where the text is accompanied by decorative graphics. In some cases there is nothing special that needs to be added to make these sections work. But in cases where there is a repeating layout of "Graphic + Heading + Text" there is an additional illu-section class added to the grid-container that surrounds these elements to adjust the spacing and sizing of the text and image elements in the section. 

                  <div class="grid-container grid-gap-30 illu-section">
                    <div class="cell"> [Image] </div>
                    <div class="cell"> [Heading & Text] </div>
                    <div class="cell"> [Image] </div>
                    <div class="cell"> [Heading & Text] </div>
                  </div>

This is used on the "About the Bulletin" page, the "Participating Institutions" page, and "Vendor Resources" landing page.
