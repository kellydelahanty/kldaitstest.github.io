View and Update Multiple Assets

Select one of your orgs that has assets to generate a list of all assets under that org. You will be able to filter this list and select specific assets to make the same “bulk” update to all selected assets at once, or download a pre-filled “batch update” spreadsheet to quickly make individual edits to multiple assets before reuploading the spreadsheet in the “Upload a Batch Update File” interface.

Upload a Batch Update File

Quickly make updates to multiple assets using the Batch Update Spreadsheet. Unlike the “Bulk” update option, you do not have to make the same update to every asset. You can download a blank version of the Batch Update Spreadsheet or a prefilled-out version of the spreadsheet with selected assets through the “View Update Multiple Assets” interface on this page.
