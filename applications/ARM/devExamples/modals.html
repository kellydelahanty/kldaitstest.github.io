Modal Tests

These modals are based the "method 1" overlay component in the AITS component library that is currently in development. See Traci's full documentation of the modals. Some basic implementation notes:

  • Javascript is in the modal-sh.js file
  • Each modal must have a unique id that is then used to open and close the modal
  • By default, the modal's max width is 800px, but you can override it setting the data-modal-size attribute.
  • The main modal div always needs to the class ptn-modal-element. Additional classes may be added for specific modals (see examples below)

HTML Structure

Basic HTML for modal trigger (Can be button or link):

<button onclick="openModal('modal-id')" type="button" class="primary button">[Button/link that triggers modal]</button>

Basic HTML for the modal itself:

<div id="modal-id" class="ptn-modal-element" role="dialog" aria-modal="true" aria-labelledby="modal-title">
    <button class="ptn-modal-close" onclick="closeModal('modal-id')" aria-label="Close modal">×</button>
                                    
    <div class="ptn-modal-interior">
                                        
        <h1 id="ptn-modal-title">Main heading for the modal content</h1>
        
        [Content for the modal goes here.]
        
    </div>
</div>
